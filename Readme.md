# Web Storage — облачное файловое хранилище на ASP.NET Core

## 📝 Описание

**Web File Storage** — это веб-приложение для загрузки, хранения и управления файлами, построенное на платформе ASP.NET Core. Проект позволяет пользователям загружать файлы на сервер, просматривать список загруженных файлов, скачивать их, а также удалять ненужные файлы. Идеально подходит для создания личного файлового архива или простого корпоративного файлообменника.

## ✨ Возможности

- Загрузка файлов (поддержка любых форматов)
- Отображение списка файлов с метаданными: имя, размер, дата загрузки
- Скачивание файлов по прямой ссылке
- Удаление файлов из хранилища
- Поиск и фильтрация файлов по имени
- Базовая аутентификация (опционально, зависит от реализации)
- Конфигурируемое место хранения (локальная папка, сетевая папка)
- Логирование действий пользователей

## 🛠 Технологии

- **ASP.NET Core** (версии 6/7/8/9)
- **Entity Framework Core** (если используется БД для метаданных)
- **SQLite / PostgreSQL / SQL Server** (на выбор)
- **Bootstrap 5** (интерфейс)
- **JavaScript** (для асинхронной загрузки файлов)
- **Serilog** (логирование)
